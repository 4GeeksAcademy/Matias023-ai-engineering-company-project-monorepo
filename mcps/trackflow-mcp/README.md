# TrackFlow MCP

Servidor MCP independiente para los servicios empresariales
existentes de TrackFlow.

## Objetivo

- Consultar, crear y actualizar incidentes.
- Consultar inventario en modo estrictamente lectura.
- Proteger herramientas mediante OAuth y scopes.
- Integrarse con LangGraph a traves de MCP.

## Estado

Proyecto inicializado. Herramientas y autenticacion
pendientes de implementacion y pruebas.

No iniciar un servidor MCP publico sin autenticacion
y autorizacion verificadas.
